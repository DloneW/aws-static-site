AWS CLOUD ENGINEERING PROJECT

Deliver websites securely at scale.

A practical demonstration of static website hosting using Amazon S3, CloudFront, Route 53 and AWS Certificate Manager.

Explore the architecture View the workflow
Project status: Local development

THE SYSTEM

Four services. One delivery pipeline.

Each AWS service has a specific responsibility in delivering the website to its visitors.

01

STORAGE

Amazon S3

Stores the HTML, CSS, JavaScript and image files that make up the website.

Private origin
02

CONTENT DELIVERY

Amazon CloudFront

Caches content at edge locations and delivers website files to visitors over HTTPS.

CDN and HTTPS
03

DNS

Amazon Route 53

Connects the custom domain name to the CloudFront distribution through DNS records.

Domain routing
04

CERTIFICATES

AWS Certificate Manager

Provides the TLS certificate used to establish encrypted HTTPS connections.

TLS certificate

Security design: S3 remains private. CloudFront accesses the origin through Origin Access Control (OAC).

REQUEST LIFECYCLE

What happens when someone visits the website?

A simplified view of how the services work together.

  1. 01

    Resolve the domain

    Route 53 directs the domain to CloudFront.

  2. 02

    Establish HTTPS

    CloudFront presents its configured TLS certificate to the browser.

  3. 03

    Deliver the content

    CloudFront serves a cached response or retrieves the required file from S3.

  4. 04

    Protect the origin

    OAC allows the configured CloudFront distribution to access private S3 objects.
